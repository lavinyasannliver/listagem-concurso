## 📌 Sobre o projeto

O **Classificações de Tombos — MG** é um projeto web criado com o objetivo de tornar a consulta dos resultados do Concurso Público e do Processo Seletivo Público de 2026 mais prática e acessível.

A plataforma reúne informações organizadas por cargo, permitindo que os usuários encontrem os candidatos e consultem suas classificações sem precisar percorrer documentos extensos.

## ✨ Funcionalidades

- Consulta das classificações do Concurso Público.
- Consulta das classificações do Processo Seletivo Público.
- Listagem de candidatos organizada por cargo.
- Pesquisa para localizar candidatos pelo nome.
- Interface simples, intuitiva e acessível pelo navegador.

- JavaScript
